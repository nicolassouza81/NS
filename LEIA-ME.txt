PORTFÓLIO — NÍCOLAS SOUZA

Este pacote contém os arquivos HTML, CSS, JavaScript, imagens, catálogo de projetos e as páginas dos cases.
O projeto está 100% preparado para publicação na Hostinger, com URLs amigáveis, segurança, compressão GZIP e fluxo facilitado para inclusão de novos cases.

COMO TESTAR NO COMPUTADOR
1. Execute um servidor local a partir desta pasta:
   - Python: python -m http.server 8000 (acesse http://localhost:8000)
   - Node:   npx serve .
   - XAMPP:  Mantenha em c:\xampp\htdocs\ns (acesse http://localhost/ns/)

HOSPEDAGEM NA HOSTINGER
Envie os seguintes arquivos e pastas para a pasta pública do seu domínio (geralmente public_html):
- .htaccess (importante: certifique-se de enviar este arquivo para URLs amigáveis, cache e HTTPS)
- 404.html
- index.html
- style.css
- portfolio.css
- app.js
- portfolio.js
- projects.js
- Pasta assets/
- Pasta cases/
- Pasta projetos/

NÃO envie a pasta _backups/ (contém cópias locais antigas de segurança).

RECURSOS ATIVOS NA HOSTINGER VIA .HTACCESS:
- URLs amigáveis limpas: /projetos/ e /cases/nome-do-case/ sem index.html visível.
- Redirecionamento forçado para HTTPS seguro.
- Compressão GZIP / Deflate para alto desempenho.
- Cache de 1 ano para imagens e estilos.
- Página de erro 404 customizada integrada à identidade visual.

COMO ADICIONAR UM NOVO PROJETO FACILMENTE:
Método 1 (Automático via terminal):
Execute o gerador:
  node novo-projeto.js
Ou com argumentos:
  node novo-projeto.js meu-case "Nome do Case" ux "Resumo do case"

Método 2 (Manual):
1. Duplique a pasta cases/_template/ para cases/<identificador>/
2. Adicione as imagens correspondentes na pasta assets/
3. Abra projects.js e cadastre o novo objeto na lista projects.
   - Categorias disponíveis: ux, branding, art.
   - Para destacar na órbita da home, inclua o identificador no array featured.

AUTOMAÇÕES IMPLEMENTADAS:
- O encadeamento de "Próximo Case" no rodapé de cada projeto é gerido automaticamente pelo portfolio.js com base na ordem de projects.js.
- Os contadores de projetos (08, 09, etc.) e os números dos filtros atualizam automaticamente sem precisar alterar o HTML.
